# 用户管理页面使用说明

## 文件结构

```
frontend/
├── src/
│   ├── views/system/user/
│   │   └── index.vue                    # 用户管理页面主文件
│   ├── api/system/
│   │   └── user.ts                      # 用户管理 API 接口
│   ├── types/
│   │   ├── system.ts                    # 系统模块类型定义
│   │   └── common.ts                    # 通用类型定义
│   ├── styles/
│   │   └── global.css                   # 全局样式文件
│   └── main.ts                          # 应用入口（已导入全局样式）
└── index.html                           # HTML 入口（已添加字体）
```

## 技术栈

- **框架**: Vue 3 + TypeScript + Composition API
- **UI 组件库**: Naive UI
- **图标**: @vicons/antd
- **日期处理**: dayjs
- **字体**: Poppins (标题) + Open Sans (正文)
- **主题色**: 企业级蓝色 (#2563EB)

## 功能特性

### 1. 顶部工具栏
- **搜索框**: 支持按用户名或真实姓名模糊搜索，按 Enter 键触发搜索
- **部门筛选**: 树形下拉框，支持按部门筛选用户
- **状态筛选**: 下拉框，支持筛选启用/禁用状态
- **搜索按钮**: 触发搜索操作
- **重置按钮**: 清空所有筛选条件并重新加载
- **新增用户按钮**: 打开新增用户弹窗

### 2. 数据表格
- **列**: 序号、用户名、真实姓名、部门、角色、状态、创建时间、操作
- **状态标签**:
  - 启用: 绿色标签
  - 禁用: 红色标签
- **角色显示**: 多个角色以标签形式展示
- **操作按钮**:
  - 编辑: 打开编辑用户弹窗
  - 分配角色: 打开角色分配弹窗
  - 重置密码: 打开重置密码弹窗
  - 删除: 弹出确认对话框后删除用户
- **分页**: 支持自定义每页显示数量（10/20/50/100）
- **排序**: 支持按列排序
- **横向滚动**: 表格宽度超出时支持横向滚动

### 3. 新增/编辑用户弹窗
- **表单字段**:
  - 用户名: 3-50字符，仅支持字母、数字、下划线（编辑时不可修改）
  - 真实姓名: 2-50字符，必填
  - 手机号: 11位数字，可选
  - 邮箱: 有效邮箱格式，可选
  - 部门: 树形选择器，可选
  - 密码: 6-20字符（仅新增时必填）
  - 状态: 启用/禁用，单选
- **表单验证**: 实时验证，提交时统一校验
- **提交按钮**: 保存并关闭弹窗

### 4. 分配角色弹窗
- **角色列表**: 多选框形式展示所有可用角色
- **角色描述**: 显示角色的详细描述
- **已分配角色**: 自动勾选用户已有的角色
- **保存按钮**: 保存角色分配并刷新列表

### 5. 重置密码弹窗
- **新密码**: 6-20字符，必填
- **确认密码**: 必须与新密码一致
- **确认重置按钮**: 提交密码重置请求

### 6. 删除确认对话框
- **警告提示**: "确定要删除该用户吗？"
- **确认/取消按钮**: 确认后执行删除操作

## 响应式设计

### 桌面端 (>768px)
- 完整表格布局
- 工具栏横向排列
- 弹窗固定宽度

### 移动端 (≤768px)
- 工具栏纵向排列
- 输入框和下拉框占满宽度
- 弹窗自适应宽度
- 表格支持横向滚动

## 可访问性特性

1. **焦点状态**: 所有可交互元素有明显的焦点环（蓝色 2px 外边框）
2. **键盘导航**: 支持 Tab 键导航，Enter 键触发搜索
3. **屏幕阅读器**: 使用语义化 HTML 和 label 元素
4. **文本对比度**: 所有文本对比度 ≥ 4.5:1
5. **减少动画**: 支持 `prefers-reduced-motion` 媒体查询
6. **加载状态**: 显示 loading 指示器，防止重复提交

## API 接口

所有接口基于 `/api/system/user` 路径：

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 用户列表 | GET | `/list` | 分页查询用户列表 |
| 用户详情 | GET | `/{id}` | 获取单个用户详情 |
| 新增用户 | POST | `/` | 创建新用户 |
| 编辑用户 | PUT | `/{id}` | 更新用户信息 |
| 删除用户 | DELETE | `/{id}` | 删除用户 |
| 分配角色 | POST | `/{id}/roles` | 为用户分配角色 |
| 获取用户角色 | GET | `/{id}/roles` | 获取用户已分配的角色 |
| 重置密码 | POST | `/{id}/reset-password` | 重置用户密码 |
| 修改状态 | PUT | `/{id}/status` | 修改用户状态 |

### 辅助接口

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 角色列表 | GET | `/system/role/all` | 获取所有角色（用于分配） |
| 部门树 | GET | `/system/department/tree` | 获取部门树（用于筛选） |

## 数据结构

### 用户实体 (User)

```typescript
interface User {
  id: number                    // 用户 ID
  username: string              // 用户名
  realName: string              // 真实姓名
  phone?: string                // 手机号
  email?: string                // 邮箱
  avatar?: string               // 头像 URL
  deptId?: number               // 部门 ID
  deptName?: string             // 部门名称
  status: UserStatus            // 状态：1-启用，0-禁用
  roleIds?: number[]            // 角色 ID 列表
  roleNames?: string[]          // 角色名称列表
  createTime: string            // 创建时间
  updateTime?: string           // 更新时间
  lastLoginTime?: string        // 最后登录时间
}
```

### 查询参数 (UserQueryParams)

```typescript
interface UserQueryParams {
  current: number               // 当前页码
  size: number                  // 每页大小
  keyword?: string              // 关键词（用户名/真实姓名）
  deptId?: number               // 部门 ID
  status?: UserStatus           // 状态
  startTime?: string            // 开始时间
  endTime?: string              // 结束时间
}
```

### 表单数据 (UserFormData)

```typescript
interface UserFormData {
  id?: number                   // 用户 ID（编辑时必填）
  username: string              // 用户名
  realName: string              // 真实姓名
  phone?: string                // 手机号
  email?: string                // 邮箱
  password?: string             // 密码（新增时必填）
  deptId?: number               // 部门 ID
  status: UserStatus            // 状态
}
```

## 常见问题

### Q: 如何修改主题色？
A: 修改 `/src/styles/global.css` 中的 `--primary-color` 变量。

### Q: 如何添加新的筛选条件？
A:
1. 在 `UserQueryParams` 类型中添加新字段
2. 在工具栏添加对应的输入组件
3. 在 `handleSearch` 函数中处理新的筛选逻辑

### Q: 如何自定义表格列？
A: 修改 `columns` 数组，添加或删除列配置。

### Q: 如何处理 API 错误？
A: 所有 API 调用都在 try-catch 块中，错误会通过 `message.error()` 显示给用户。
